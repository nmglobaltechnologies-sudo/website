# 🌐 NM Global Technologies — Website Build Plan

## 1. Overview

**Client:** NM Global Technologies  
**Goal:** Build a modern, professional, and performance-optimized corporate website that effectively communicates NM Global Technologies’ IT and consulting services, establishes trust, and encourages client inquiries.  

**Inspiration:** [Kenai Technologies (kenai-us.com)](https://www.kenai-us.com)  
**Enhancements:** Improved speed, stronger CTAs, better content readability, regular updates, and interactive engagement.

---

## 2. Website Objectives

- Present NM Global Technologies as a trusted provider of **ERP, Cloud, and Managed IT services**.  
- Highlight **service expertise**, **industry experience**, and **global presence**.  
- Drive inquiries through clear **calls-to-action (CTAs)**.  
- Support long-term SEO and content marketing through a blog/resource hub.  
- Ensure **mobile-first** responsiveness and accessibility compliance (WCAG AA).

---

## 3. Target Audience

- Enterprise and mid-sized businesses looking for IT solutions or ERP implementation.  
- Potential partners, investors, and job seekers.  
- Global clients (primarily US, Europe, and India).

## 5. Visual & UI Design System

### 🎨 Brand Colors
- **Primary Blue:** `#274C77` (Trust, corporate feel)  
- **Accent Blue:** `#6096BA`  
- **Sky Blue:** `#A3CEF1`  
- **Neutral Gray:** `#8B8C89`  
- **White / Off-white:** For background and readability

### 🧩 Typography
- **Headings:** `Poppins` or `Montserrat` — bold, clean  
- **Body Text:** `Open Sans` or `Lato` — highly readable  
- Line height: `1.6` for good legibility

### 🖼️ Imagery & Iconography
- Use **custom service illustrations** or **flat icons** for services.  
- Show **real team and office images** for authenticity.  
- Maintain **consistent image aspect ratios** (16:9 for banners, 1:1 for icons).  

### 🧭 Layout & Components
- Responsive **grid-based layout** (12-column using Tailwind or Bootstrap).  
- Prominent **CTA buttons** (“Talk to Us”, “Request a Consultation”) with gradient accent.  
- Use **micro-interactions**: hover effects, fade-in animations.  
- Sticky header with quick navigation.

## 9. Technical Stack

| Layer | Recommendation | Notes |
|-------|----------------|-------|
| **Frontend Framework** | Next.js (React + SSR) | For SEO-friendly dynamic pages |
| **Styling** | Tailwind CSS | Rapid responsive UI |
| **Forms / Contact** | React Hook Form + EmailJS / AWS SES | For inquiry forms |
| **Backend / CMS** | Sanity.io or Strapi | Optional — for blog & dynamic content |
| **Hosting** | Vercel / AWS Amplify / Netlify | Fast CDN + easy CI/CD |
| **Analytics** | Google Analytics 4 | Visitor tracking |
| **SEO Tools** | Next SEO / Meta tags | Structured data + OG tags |
| **Performance Tools** | Image optimization + lazy loading | Lighthouse score >90 |

---

## 10. Performance & Accessibility Goals

- **Page Load Time:** < 2.5s on 4G  
- **Lighthouse Scores:**  
  - Performance ≥ 90  
  - Accessibility ≥ 90  
  - SEO ≥ 90  
- **Responsive Design:** Mobile-first, test across devices.  
- **Accessibility:** ARIA labels, proper alt text, contrast ratio > 4.5:1
